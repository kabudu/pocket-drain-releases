# Pocket Drain releases

Official signed releases of Pocket Drain, a competitive life board game inspired by Jones in the Fast Lane.

Release acceptance is in progress. No public game packages are available yet.

Approved versions will appear under [GitHub Releases](https://github.com/kabudu/pocket-drain-releases/releases), with platform packages, checksums, signatures and release notes. The game source is maintained separately in a private repository.

Do not post private game invitations, player identities, saves or credentials here. Public Issues and Discussions are disabled.
